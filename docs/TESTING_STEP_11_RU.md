# SAOIM — этап 11: тестирование

## 1. Автоматические тесты

Обычный прогон:

```powershell
.\scripts\run-tests.ps1
```

или:

```powershell
mvn clean verify
```

Результаты:

- `target/surefire-reports` — отчёты JUnit;
- `target/site/jacoco/index.html` — покрытие;
- `target/failsafe-reports` — интеграционные тесты MySQL.

Обычный прогон не требует базы данных и не открывает JavaFX-окно. Анимации отключаются системными параметрами Surefire.

## 2. MySQL smoke test

Подготовьте `.env` с рабочими `DB_URL`, `DB_USER` и `DB_PASSWORD`, затем выполните:

```powershell
.\scripts\run-db-integration-tests.ps1
```

Профиль `integration-tests` проверяет соединение, запускает существующую миграцию и убеждается, что доступны таблицы `accounts`, `profiles`, `app_categories` и `app_shortcuts`.

Не запускайте этот профиль против производственной базы без резервной копии: `initDatabase()` может применить миграции проекта.

## 3. Мониторы и DPI

Проверить конфигурации:

- один монитор 100%;
- один монитор 125%, 150% и 200%;
- два монитора одинакового DPI;
- два монитора со смешанным DPI;
- основной монитор слева и справа;
- монитор с отрицательной глобальной координатой;
- открытие на каждом мониторе по положению курсора.

После полного закрытия SAOIM следующий жест должен разрешать выбор другого монитора. Переходы `STANDARD_MENU ↔ PROFILE` не должны менять зафиксированный монитор.

## 4. Жесты, Esc и ПКМ

Проверить последовательность:

1. `HIDDEN + жест` на рабочем столе → стандартное меню.
2. Скрытый SAOIM и активное стороннее окно → жест игнорируется.
3. `PROFILE + жест` → стандартное меню.
4. `Esc` во вложенной категории → уровень выше.
5. `Esc` на корне профиля → стандартное меню.
6. `Esc` в стандартном меню → полное скрытие.
7. `Esc` при открытом редакторе → закрыть только редактор.
8. ПКМ по свободной области → скрыть SAOIM и не открыть меню рабочего стола Windows.
9. ПКМ внутри карточки стандартного меню → не закрывать интерфейс.

Выполнить не менее 50 быстрых чередований жеста, `Esc`, открытия профиля и возврата. После серии переходов проверять `opacity`, масштаб и расположение визуально: интерфейс не должен оставаться полупрозрачным или смещённым.

## 5. Дерево и нагрузка

Автоматические тесты создают дерево глубиной 300 и смешанный уровень из 2,000 элементов.

Для реального UI можно применить `docs/STAGE11_LOAD_TEST_DATA.sql`. Перед запуском задайте корректный `@account_id`. Скрипт создаёт отдельный корень `[TEST11] Нагрузочный тест`, цепочку глубиной 100, 200 дочерних категорий и 1,000 URL-ярлыков.

Проверить:

- открытие корня и постраничность;
- вход на глубину не менее 20 уровней;
- `Esc` на каждом уровне;
- создание, перемещение и сортировку рядом с тестовыми данными;
- отсутствие зависания JavaFX Application Thread;
- корректное сокращение длинных названий.

## 6. Удаление и история

Создать поддерево с категориями и ярлыками. Проверить:

- подтверждение показывает масштаб удаления;
- удаление выполняется одной операцией;
- `Ctrl+Z` восстанавливает идентификаторы, родителей, порядок и закрепление;
- `Ctrl+Shift+Z` повторяет удаление;
- несколько удалений отменяются в обратном порядке;
- ошибка базы при undo не удаляет команду из истории;
- смена аккаунта очищает сессионную историю.

## 7. Ярлыки и недоступные цели

Отдельно проверить `.exe`, `.lnk`, файл, папку, HTTP/HTTPS URL и AUMID Microsoft Store.

Для каждого локального типа:

1. Запустить существующую цель.
2. Переименовать или удалить цель вне SAOIM.
3. Обновить профиль.
4. Убедиться, что ярлык остаётся в аккаунте, отмечается недоступным и не вызывает падения.
5. Исправить `target` через редактор без удаления ярлыка.

## 8. Потеря MySQL

1. Открыть профиль и выполнить обычную операцию.
2. Остановить MySQL.
3. Попробовать обновить, создать, переместить, удалить и отменить удаление.
4. Убедиться, что UI не зависает, показывает понятную ошибку и не повреждает историю.
5. Запустить MySQL снова.
6. Обновить профиль и проверить целостность данных.

## 9. Диагностика

```powershell
.\scripts\collect-diagnostics.ps1
```

Скрипт сохраняет сведения о Windows, Java, Maven, видеокарте и мониторах в `target/stage11-diagnostics/environment.txt`. `.env` и пароли не копируются.

Заполните `docs/TEST_RESULTS_TEMPLATE_RU.md` для финального решения о готовности первой версии.
